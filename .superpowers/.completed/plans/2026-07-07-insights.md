# Insights Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Trends "Insights" section that surfaces up to four plain-language, statistically-gated observations about the baby's sleep pattern (wake-window calibration, overtired correlation, nap-duration trend, method/quality comparison), reusing the precision-weighted shrinkage primitives already shipped in PR #98.

**Architecture:** Four new pure `derive.*()` functions in `js/store.js`, one new shared `betaBinomialShrinkage` helper alongside the existing `shrinkageWeight`/`noiseFloorVariance` helpers, an aggregator `derive.insights()`, and a new render function in `js/trends.js` that renders a `.card.insights-card` above the existing stat grid. No new state, no new UI interactions (not dismissible — see Global Constraints).

**Tech Stack:** Vanilla JS (ES modules), `node --test` for unit tests, Playwright for the new `tests/insights.test.js` E2E suite.

## Global Constraints

Copied verbatim from `docs/design/insights-and-shrinkage.md`'s "Insights (new)" section:

- One insight = one number, one sentence. No paragraphs, no charts, no dashboards.
- Sample size sits behind a tap/disclosure, never in the primary sentence.
- No causal or blame language ("because", "you should", "your baby is behind"). State the association plainly.
- No point-forecasts ("bedtime will be at 7:32"); windows/directions only.
- Below the legibility/sample-size threshold, the insight doesn't render at all — never a "not enough data yet" placeholder or nag.
- Insight #2 (overtired correlation) must use a **lagged** design: nap *i*'s overshoot vs. nap *i+1*'s quality, never a same-nap correlation (confounded and explicitly ruled out by the spec).
- Out of scope: aggregate cross-family population priors, WHO growth percentile bands, local JSON export.
- Follow repo-wide rules from `/workspace/hearth/CLAUDE.md`: bump the version (`scripts/bump-version.sh`) before every commit that changes a cached user-facing asset, keep `js/changelog.js` in sync with user-visible changes, Conventional Commits for every commit message, run `node --test js/store.test.js` plus the touched Playwright suite before merging.

// Beta-Binomial shrinkage: pulls an observed proportion (successes/n) toward
// a prior proportion using priorPseudoN pseudo-trials of weight, the same
// precision-blending idea as shrinkageWeight applied to proportions instead

function betaBinomialShrinkage(successes, n, priorP, priorPseudoN = 8) {
  return (successes + priorP * priorPseudoN) / (n + priorPseudoN);

```js
  // Insight #2: lagged design per the spec — nap i's wake-window overshoot
  // vs. nap i+1's quality, NOT a same-nap correlation (that's confounded:
  // a bad nap could itself be why the window looks long). "Overshoot" means
  // the wake gap before nap i+1 ran past that position's predicted high.
  overtiredCorrelation() {
    const cutoffMs = Date.now() - 21 * DAY;
    const ss = sleeps().filter((e) => e.end && new Date(e.end).getTime() > cutoffMs)
      .slice().sort((a, b) => new Date(a.start) - new Date(b.start));
    const overshotGood = [];
    const onTimeGood = [];
    for (let i = 0; i < ss.length - 1; i++) {
      const nap = ss[i], nextNap = ss[i + 1];
      if (!nextNap.end) continue;
      const wakeStart = new Date(nap.end);
      const wakeEnd = new Date(nextNap.start);
      if (wakeEnd <= wakeStart) continue;
      const wakeMin = (wakeEnd - wakeStart) / MIN;
      if (wakeMin < 10 || wakeMin > 360) continue;
      const pos = wakePosition(wakeStart);
      if (pos === 'night') continue;
      const pred = derive.wakeWindowPrediction(pos);
      if (!pred) continue;
      const isGood = nextNap.quality === 'Good' || nextNap.quality === 'Great';
      (wakeMin > pred.high ? overshotGood : onTimeGood).push(isGood);
    }
    if (overshotGood.length < 5 || onTimeGood.length < 5) return null;
    const totalGood = overshotGood.filter(Boolean).length + onTimeGood.filter(Boolean).length;
    const overallGoodRate = totalGood / (overshotGood.length + onTimeGood.length);
    const overshotRate = betaBinomialShrinkage(overshotGood.filter(Boolean).length, overshotGood.length, overallGoodRate, 8);
    const onTimeRate = betaBinomialShrinkage(onTimeGood.filter(Boolean).length, onTimeGood.length, overallGoodRate, 8);
    if (onTimeRate - overshotRate < 0.15) return null;
    const name = state().baby.name || 'Your baby';
    return {
      id: 'overtired-correlation',
      text: `When ${name} stays awake past the usual window, the next nap tends to go worse.`,
      sampleSize: overshotGood.length + onTimeGood.length,
    };
  },
```

```js
  // Insight #3: compares the last 14 days of nap duration against the 14
  // days before that (28-day lookback total). Each window's weighted median
  // is shrunk toward the existing age-bucket nap-duration assumption
  // (js/store.js:638's `m < 6 ? 60 : 80`, the only nap-duration prior this
  // codebase has — reused here rather than inventing a new number) with an
  // assumed prior variance of 400 (SD ~20 min), using the same
  // shrinkageWeight/noiseFloorVariance primitives as the wake-window blend.
  napDurationTrend() {
    const now = Date.now();
    const cutoff = now - 28 * DAY;
    const windowSplit = now - 14 * DAY;
    const naps = sleeps()
      .filter((e) => e.end && new Date(e.start).getTime() > cutoff && wakePosition(new Date(e.start)) !== 'night')
      .map((e) => ({ date: new Date(e.start), durMin: (new Date(e.end) - new Date(e.start)) / MIN }))
      .filter((n) => n.durMin > 0 && n.durMin < 180);
    const recent = naps.filter((n) => n.date.getTime() >= windowSplit).map((n) => ({ value: n.durMin, weight: recencyWeight(n.date, now) }));
    const prior = naps.filter((n) => n.date.getTime() < windowSplit).map((n) => ({ value: n.durMin, weight: recencyWeight(n.date, now) }));
    if (recent.length < 5 || prior.length < 5) return null;
    const m = ageMonths();
    const expected = m < 6 ? 60 : 80;
    const ageVariance = 400;
    const shrinkToward = (obs) => {
      const median = weightedMedian(obs);
      const variance = noiseFloorVariance(weightedVariance(obs) ?? ageVariance, obs.length);
      const w = shrinkageWeight(variance, obs.length, ageVariance);
      return w * median + (1 - w) * expected;
    };
    const recentShrunk = shrinkToward(recent);
    const priorShrunk = shrinkToward(prior);
    const diff = recentShrunk - priorShrunk;
    if (Math.abs(diff) < 10) return null;
    const name = state().baby.name || 'Your baby';
    const direction = diff > 0 ? 'longer' : 'shorter';
    return {
      id: 'nap-duration-trend',
      text: `${name}'s naps have run about ${Math.round(Math.abs(diff))} min ${direction} over the last two weeks than the two weeks before.`,
      sampleSize: recent.length + prior.length,
    };
  },
```

  // Insight #4: Beta-Binomial shrinkage of quality good-rate between the
  // self-settle method ('On own in bed') and every other (assisted) method,
  // each shrunk toward the baby's own overall good-rate so a small group
  // isn't read as a hard fact.
  methodQualityComparison() {
    const cutoff = Date.now() - 21 * DAY;
    const withMethod = sleeps().filter((e) => e.end && new Date(e.end).getTime() > cutoff && e.method);
    const selfSettle = withMethod.filter((e) => e.method === 'On own in bed');
    const assisted = withMethod.filter((e) => e.method !== 'On own in bed');
    if (selfSettle.length < 5 || assisted.length < 5) return null;
    const isGood = (e) => e.quality === 'Good' || e.quality === 'Great';
    const overallGoodRate = withMethod.filter(isGood).length / withMethod.length;
    const selfRate = betaBinomialShrinkage(selfSettle.filter(isGood).length, selfSettle.length, overallGoodRate, 8);
    const assistedRate = betaBinomialShrinkage(assisted.filter(isGood).length, assisted.length, overallGoodRate, 8);
    const diff = selfRate - assistedRate;
    if (Math.abs(diff) < 0.15) return null;
    const name = state().baby.name || 'Your baby';
    const better = diff > 0 ? 'settling on their own' : 'being helped to sleep';
    return {
      id: 'method-quality-comparison',
      text: `${name}'s sleep quality tends to be better when ${better}.`,
      sampleSize: withMethod.length,
    };
  },
